VICTUS GLOBAL SIGNATURE — FREE WEB-HOSTED VERSION

This package is ready for GitHub Pages (free).

1. Create a free GitHub account if needed.
2. Create a new PUBLIC repository, for example: victus-email-signature
3. Upload index.html and the entire assets folder to the repository root.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch: main, folder: / (root), then Save.
7. GitHub will give you an HTTPS site such as:
   https://YOUR-USERNAME.github.io/victus-email-signature/
8. Open that URL in Edge or Chrome. Confirm every logo/icon appears.
9. Select ONLY the visible signature, copy it, then paste it into New Outlook > Settings > Accounts > Signatures.
10. Send a test email to a different mailbox/device.

IMPORTANT:
- Do not rename the assets folder or image files unless you also update index.html.
- Keep the repository public, otherwise email recipients cannot load the images.
- Remote images can still be blocked by a recipient's mail privacy settings until they choose to display images. This is normal for externally hosted email images.
