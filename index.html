Use in Microsoft 365 / Outlook

  1. Open this editor on the published GitHub Pages URL and enter the employee's details.
  2. Choose Copy formatted signature.
  3. Paste into the Outlook signature editor (in new Outlook / Outlook on the web: Settings → Accounts → Signatures). Save.
  4. Send a test message to an external address and a mobile device to confirm the logo, social links and video link display as intended.

The downloaded file is a clean HTML signature without the editor and can be reused as a template or adapted for company-wide deployment.
